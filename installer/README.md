# Installer

Hier liegt immer der aktuelle Installer, damit man nicht erst in die Releases muss.

- `PythonLearner-0.0.3-windows-Installer.exe`: Windows, einfach ausführen. Python muss nicht installiert sein. Wenn Windows "unbekannter Herausgeber" sagt: Weitere Infos -> Trotzdem ausführen.
- `PythonLearner-0.0.3-mac-buildkit.zip`: Mac (Apple Silicon), auspacken und `Build Python Learner.command` doppelklicken, baut die .app/.dmg direkt auf dem Mac.
- `SHA256SUMS.txt`: Prüfsummen

Das portable Zip (ohne Installation) gibts nur bei den GitHub Releases, das wäre hier zu groß.
Ältere Versionen ebenfalls unter Releases.
